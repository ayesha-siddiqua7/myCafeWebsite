# Lavender Cafe

A sleek and modern web application crafted for a cafe experience, equipped with a dynamic menu calculator, an automated booking module, consumer reviews, and an adjustable visual theme.

## Core Capabilities

* **Dynamic Menu & Checkout:** Filter through curated categories of artisan coffee, pastries, main courses, and signature blends with automated pricing calculations.
* **Seating Allocations:** Secure dining spaces online by choosing between interior dining halls or open-air garden seating.
* **Review Console:** Share dining experiences using interactive rating scores along with a message board utilizing a real-time character tracker.
* **Ambient Lighting Switch:** Smoothly transition the interface layout between high-contrast light mode and a battery-saving dark color scheme.
* **Device Fluidity:** Fluid grid structures engineered to scale perfectly across smart display panels, tablets, and desktop workstations.

## Technology Stack

* **HTML5:** Structuring semantic layout blocks and data entry views.
* **CSS3:** Handling aesthetic styling properties, micro-interactions, responsive media queries, and color palettes.
* **JavaScript:** Processing client-side calculation parameters, event listeners, input evaluation, and state changes.
